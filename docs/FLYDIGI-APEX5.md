# Flydigi APEX 5 — план отдельной реализации

В отличие от Switch Pro, здесь протокол закрыт: у Flydigi нет открытой
документации, всё интересное — за перехватом трафика их приложения Space. Но
часть реализуема уже сейчас, и её стоит отделить от реверс-части.

## Что известно с этого стола (из DESK-DEEP-DIVE)

- **Пад (донгл `37d7:2501`)**: XInput (slot 0), плюс эмулированные клав/мышь.
  Заряд по XInput донгл НЕ отдаёт — врёт «проводной, батареи нет».
- **Док (`37d7:6001`, page 0xFFA0)**: **вещает без запроса**, раз в секунду:
  `00 5A A5 EF 08 01 00 39 00 06 00 37 00 …`. `5A A5` — маркер Flydigi.
  `0x39=57`, `0x37=55` — очень похоже на два заряда (пад на площадке +
  запасной аккумулятор в слоте дока).
- **Донгл тоже имеет page 0xFFA0** (MI_02) — но это канал запрос-ответ, на
  прослушку молчит: нужен реверс.

## Трек A — реализуемо без реверса (делать первым)

1. **Заряд с дока, пассивно.** Открыть 0xFFA0 дока, читать без записи, парсить
   `5A A5`-кадр. Даёт заряд на строке APEX 5, **когда пад на зарядке**.
   Блокер — ровно одна проверка (VERIFY-LATER п.1): снять пад, увидеть какой
   байт замер. После этого — маленький пассивный «драйвер дока»: не отдельное
   устройство, а поставщик заряда для строки геймпада (склейка по каталогу
   уже есть — док и так внутри APEX 5).
2. **Вибротест** через XInput SetState — универсально, уже описано.
3. **Диагностика стиков/кнопок** через XInput GetState — страница-тестер.

Трек A превращает APEX 5 из «строки с чипами» в устройство с зарядом и
базовой страницей — без единого вендорского запроса.

## Трек B — требует перехвата Space (реверс, отдельный вечер)

Метод: USBPcap + Wireshark (или их встроенный лог), запустить Flydigi Space,
подвигать каждую настройку, сопоставить кадры 0xFFA0 запрос↔ответ. Цель —
вытащить, что именно Space умеет. Ожидаемо (по фичам Space):

| Кандидат | Зачем |
|---|---|
| Заряд пада **в игре** (не только на доке) | закрыть пробел трека A |
| Ремап кнопок и **лепестков** | лепестки видны только их протоколу |
| Триггер-режимы (аналог/цифра, ход) | «hair trigger» |
| Гироскоп вкл/чувствительность | mouse-joystick |
| Профили (сохранить/переключить/на игру) | как артборд 9c |
| Зоны подсветки | если есть |
| Мёртвые зоны стиков | тюнинг |

Когда протокол вскрыт — реализация как у RACE: код на протокол, модели —
данные. Флаг unverified снимается по мере подтверждения каждой команды.

## Что НЕЛЬЗЯ и через Space (честные границы)

- Лепестки как «отдельные кнопки» в играх без назначения — их всё равно
  назначают на существующие кнопки; «свободного» лепестка не бывает.
- Заряд по XInput — тупик навсегда (донгл врёт), только 0xFFA0.

## Порядок

Трек A целиком (после одной проверки байтов) → затем, если захочешь глубину,
один перехват Space открывает трек B разом. Чек-листы — VERIFY-LATER пп.1, 7.
