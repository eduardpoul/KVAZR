# Подсветка и DPI — что можно на твоих устройствах

Прямой ответ по каждому вопросу, на основе реальных дампов этого стола
(`kvazr --desk`), а не общих слов.

## Подсветка (RGB)

Тут два разных «можно»: можно ли **вообще у этого класса** и есть ли она **у
конкретно твоей модели**.

| Устройство | RGB есть? | Управляется? | Как |
|---|---|---|---|
| **Superlight 2** (мышь) | **нет физически** | — | киберспорт-мышь без подсветки; в её таблице HID++ нет ни одной световой фичи (0x8070/0x8071/0x1990 отсутствуют) — подтверждено дампом |
| **NuPhy Air96** (клава) | да | по кабелю (VIA), не по донглу | VIA-канал `qmk_rgb_matrix`: яркость/эффект/цвет, чтение и запись — universal для VIA-клав |
| **QuadCast S** (микро) | да | да, но вендорский формат | интерфейс `0xFF90` (65/65) — RGB-протокол HyperX, формат уже задокументирован проектом OpenRGB, т.е. дёшево |
| Мыши/клавы Logitech с RGB | да | да | HID++ фичи 0x8070/0x8071 — universal, драйвер уже умеет читать таблицу |

**Итого по подсветке:**
- **Клавиатура (Air96)** — да, но только когда подключишь **кабелем** (VIA
  через донгл не идёт — проверено трижды). Universal для всех VIA-клав.
- **Микрофон (QuadCast)** — да, формат HyperX известен из OpenRGB; это
  «вендорский, но с готовой чужой документацией» — не полный реверс.
- **Твоя мышь** — нечем, у неё нет светодиодов. У других мышей Logitech с RGB
  — да, тем же классовым драйвером.

Общее правило: **клавиатуры и мыши** с RGB — universal (VIA / HID++ сами
описывают световые каналы). **Микрофоны** — почти всегда вендорский протокол
(единого класса для «RGB микрофона» нет), но популярные модели уже вскрыты
OpenRGB, откуда берём формат.

## DPI на мышке — и сохранение в мышку

**Да, полностью — и сохранение именно в память мыши.** Твоя Superlight 2
отдала в таблице ровно те фичи, что нужны:

| Фича | Что даёт |
|---|---|
| `0x2202` ExtendedAdjustableDPI | список ступеней DPI, текущая, раздельный X/Y, **запись** |
| `0x8061` ExtendedReportRate | частота опроса (у тебя сейчас 1 кГц), до 8 кГц, запись |
| `0x8100` **OnboardProfiles** | **профили в памяти мыши** — вот это и есть «сохранить в мышку» |

Ключевое: **DPI и профили HID++ хранятся в самой мыши**, не в нашем софте и не
в облаке Logitech. Меняешь DPI → пишется в память мыши → работает на любом
компе без всякого приложения, как ты и хочешь. `0x8100` OnboardProfiles — это
несколько слотов прямо в железе (как онбордные профили в артборде 9c): DPI,
частота, назначения кнопок, — переключаемые кнопкой на мыши.

Это **universal** для всей линейки Logitech: любая их мышь отдаст свои фичи
через ту же таблицу, драйвер один. Реализация — очередь того же HID++ драйвера,
что уже читает заряд; чтение/запись по документированным функциям (лейаут
ответа 0x2202 сверить с Solaar — raw уже печатается пробником для сверки).

**Чего НЕ можем по DPI:** мыши других вендоров (Razer Synapse, Glorious и
т.п.) — у каждого свой протокол, класса нет. Только Logitech (HID++) и, через
кабель, VIA-мыши (редкость).

## Сводка одной строкой

- **Подсветка:** клава — да (кабель/VIA), микро — да (формат из OpenRGB),
  твоя мышь — нечем (нет RGB), другие RGB-мыши Logitech — да.
- **DPI + сохранение в мышку:** да, полностью, и хранится в самой мыши —
  universal для Logitech, очередь существующего драйвера.
