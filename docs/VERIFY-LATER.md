# Проверить, когда руки у стола

Бэклог наблюдений, каждое — минуты. Пробники уже собраны, команды готовы.

## Требуют рук

1. **Док Flydigi — какой байт чей.** `maxwell --desk` (раздел прослушивания),
   снять пад с площадки → какой из двух байтов (0x39/0x37 в кадре `5A A5 …`)
   замрёт или пропадёт, тот и пад; второй — запасной аккумулятор в слоте.
   Это открывает заряд на строке APEX 5 при зарядке — пассивно, без реверса.
2. **QuadCast: tap-mute и ручка.** `maxwell --live` (слушает всё разом,
   30 секунд): тапнуть mute — ждём кадр на странице телефонии 0x000B;
   покрутить ручку gain — смотрим, оживёт ли page 0xFFFF (in 8).
3. **AirPods: открыть крышку кейса рядом с ПК** и `maxwell --airpods` —
   должны прийти проценты L/R/кейса с флагами зарядки (реклама 0x07).
4. **Air96: пощёлкать клавиши/колесо во время `maxwell --live`** — вдруг донгл
   что-то шлёт по 0xFF31 на события.
5. **APEX 5: режимы пада.** Переключить пад в DInput/Switch-режим (комбинация
   на паде) и `maxwell --desk`: изменится ли набор интерфейсов и число кнопок —
   в не-Xbox режимах лепестки могут стать видимыми отдельными кнопками.

6. **Switch Pro Controller — при подключении.** Протокол готов заранее
   (`Maxwell.Race/Protocol/SwitchPro.cs` + тесты на документированных байтах).
   По Bluetooth: спарить — говорит сразу. По USB: сперва handshake `80 02`,
   потом `80 04`. Проверить по порядку: device info (subcmd 0x02), перевод в
   режим 0x30, заряд из байта 2 (4 ступени + зарядка), цвета корпуса из SPI
   0x6050 (пад сам знает, какого он цвета — можно красить строку). Расхождение
   с тестами = расхождение пада с документацией, фиксировать дампом.

## Требуют перехвата трафика (реверс, по одному вечеру)

6. **NuPhy Console ↔ донгл (0xFF31):** USBPcap/Wireshark во время работы их
   софта. Цель — команда заряда по 2.4G. Протокол наверняка простой.
7. **Flydigi Space ↔ пад/донгл (0xFFA0):** тот же метод. Цель — заряд в игре,
   ремап лепестков, триггеры, гироскоп, профили (всё, что умеет Space).

## Требуют сверки с чужим кодом (за столом не нужны)

8. **HID++ 0x2202:** лейаут ответа getSensorDpi сверить с Solaar — наш парс
   выдал «3 / 45062», raw в пробнике печатается для сверки.
9. **QuadCast RGB (0xFF90):** формат взять из OpenRGB (уже задокументирован).
10. **VIA по кабелю:** подключить Air96 кабелем — появится 0xFF60, драйвер VIA
    можно писать и проверять (снимок-модель описана в CLASS-PROTOCOLS.md).
