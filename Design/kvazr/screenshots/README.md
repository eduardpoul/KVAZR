# Отрисованные артборды

Дизайн лежит рядом в `.dc.html`, но эти файлы шаблонизированы: без JS они не
разворачиваются, а разметку приходится читать регулярками. Здесь то же самое уже
отрисовано, поэтому **сверяться надо с этими картинками, а не с HTML**.

Экран не считается готовым, пока он не отрисован офлайн (`--dump-pages`,
`--dump-thumbs`, `--dump-icons`) и не положен рядом со своим файлом отсюда.
Размеры при этом не переписываются глазами — их снимает `tools/design-tokens.py`
и кладёт в `src/Maxwell.App/Themes/Metrics.axaml`.

| Файл | Что на нём |
|---|---|
| `01-dashboard-light-dark` | Дашборд, светлая и тёмная. Одна карточка со строками 84 px |
| `04-tray-icons`, `04b-tray-4x` | Иконка трея: размеры × темы × состояния |
| `05a-maxwell-full-access` | Страница устройства, полный доступ |
| `05b-maxwell-dongle-only` | Только мониторинг: разделы гаснут с подписью «по кабелю» |
| `05c-maxwell-boom-detached` | Бум отсоединён — текущее состояние железа |
| `06a-mouse-pointer` | Мышь · Указатель |
| `06b-keyboard-keymap` | Клавиатура · раскладка со слоями |
| `06c-no-devices` | Устройств нет: три карточки классов и кнопка поиска |
| `07a-settings`, `07b-about` | Параметры и «О программе» |
| `08a`–`08c` | Гарнитура: питание, связь, диалог прошивки |
| `09a`–`09c` | Мышь: питание, связь, профили и ButtonMap |
| `10a`–`10d` | Клавиатура: питание, связь, подсветка, профили и слои |
| `11a`–`11d` | Геймпад, AirPods, неопознанное BT, колонка |
| `12a`–`12d` | Флайаут: свёрнут, раскрыт, прочие классы, светлая тема |
| `13a`–`13c` | Контекстное меню строки, «Скрытые» в параметрах, микрофон |

Имя приложения в этих макетах — «Devices Hub». В коде оно уже KVAZR: переименование
случилось в отдельном документе идентики и в экраны не вернулось.
