Turn 14 · Базовый уровень: страница класса
Страницы устройств, собранные только из проверенных возможностей
Уровень «по умолчанию» для класса: только то, что есть на любом устройстве этого типа — система, Core Audio, XInput, HID++/VIA. Там, где базовым путём данных нет, вместо контрола стоит строка-факт с причиной. Личные строки особых устройств — в Turn 15. 14a гарнитура по Bluetooth, 14b та же по донглу, 14c микрофон, 14d мышь HID++, 14e клавиатура за донглом, 14f клавиатура по кабелю, 14g геймпад XInput, 14h колонка.
